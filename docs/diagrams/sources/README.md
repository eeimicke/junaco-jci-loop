# Kanonische Diagrammquellen

Die `.mmd`-Dateien enthalten die strukturell verbindlichen Mermaid-Quellen der Dokumentationsgrafiken. Übersetzte Dokumente dürfen Beschriftungen übersetzen, aber keine JCI-Entität oder Beziehung verändern.

| Datei | Inhalt |
|---|---|
| `jci-loop.mmd` | Gesamtzusammenhang des Loops |
| `entity-model.mmd` | Typordnung der gespeicherten Entitäten |
| `future-chain.mmd` | Zukunftskette und WHY-Pfad |
| `rof-model.mmd` | Organisation, Team, Mitglied und Rollenaktivierung |
| `erof-model.mmd` | personengebundener Umweltkontext |
| `task-verification.mmd` | Arbeit, Ergebnis und Prüfung |
| `ran-evaluation.mmd` | Regelauswertung und Konflikt |
| `sync-history.mmd` | Änderung, Synchronisation und Historisierung |
