This page documents the public namespace of the JUNACO Continuous Integration Model for Organisations:

https://eeimicke.github.io/junaco-jci-loop/ns/jci/1.0#

Die fachlich kanonische Beschreibung steht in JCI_CONTEXT.md. Die formale Typ- und Beziehungsliste steht in JCI_ONTOLOGY.md. Bei Abweichungen sind diese versionierten Quelldokumente maßgeblich.

The canonical domain description is available in the German JCI_CONTEXT.md. The controlled English companion is available in docs/en/JCI_CONTEXT.md. If they differ, the German source documents govern.
